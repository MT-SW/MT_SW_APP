### Czym jest InfluxDB 3 Core?
InfluxDB 3 Core to open source silnik danych szeregów czasowych działający na jednym węźle. Jest licencjonowany na MIT i Apache 2.0, a strona opisuje go jako silnik do danych w czasie rzeczywistym. Zoptymalizowany jest pod szybki zapis i zapytania o najnowsze dane poniżej 10 ms.

Słowa: influxdb 3 core, szereg czasowy, open source, MIT, Apache 2.0, czas rzeczywisty
Źródło: https://www.influxdata.com/products/influxdb/ (sprawdzono 2026-10)

### Z czego zbudowany jest InfluxDB 3 Core?
Strona podaje, że InfluxDB 3 Core jest napisany w Rust i oparty na stosie FDAP, czyli Apache Arrow Flight, DataFusion, Arrow i Parquet.

Słowa: influxdb 3, Rust, FDAP, Arrow Flight, DataFusion, Parquet, stos
Źródło: https://www.influxdata.com/products/influxdb/ (sprawdzono 2026-10)

### Jakich języków zapytań używa InfluxDB 3 Core?
Strona wymienia natywny SQL i InfluxQL, czyli język podobny do SQL dla danych szeregów czasowych. Dane są zapisywane w kolumnowym formacie Parquet na tanim magazynie obiektów.

Słowa: influxdb 3, SQL, InfluxQL, Parquet, magazyn obiektów, zapytania
Źródło: https://www.influxdata.com/products/influxdb/ (sprawdzono 2026-10)

### Gdzie można uruchomić InfluxDB 3 Core?
Strona podaje, że InfluxDB 3 Core działa na urządzeniach brzegowych, serwerach lokalnych, prywatnej chmurze i w konfiguracjach hybrydowych. Instalacja jest dostępna na Linuksie, Macu, RHEL, Dockerze i Windowsie. Dla pełnych wersji są też opcje Enterprise oraz zarządzane usługi chmurowe.

Słowa: influxdb 3 core, instalacja, Docker, Linux, edge, hybrydowe, chmura
