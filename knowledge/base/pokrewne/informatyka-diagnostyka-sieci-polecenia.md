# Diagnostyka sieci: podstawowe polecenia

### Do czego służą ping, traceroute, ipconfig, nslookup i netstat?
Według ComputerHope: ping sprawdza, czy komputer komunikuje się z danym adresem IP w sieci lokalnej lub zewnętrznej, więc pomaga ocenić, czy problem leży w łączności. Tracert (Windows) / traceroute (Unix) pokazuje trasę pakietu przez sieć i miejsce awarii lub spowolnienia. Ipconfig wyświetla bieżące ustawienia sieci komputera (w Linuksie odpowiednikiem jest m.in. ip addr, wiedza ogólna, nie ze źródła). Nslookup wyszukuje informacje DNS o hoście lub adresie. Netstat pokazuje statystyki protokołów TCP/IP i połączenia. Niektóre polecenia wymagają uprawnień administratora lub roota. Źródło nie podaje przykładów składni.
Słowa: ping traceroute tracert ipconfig nslookup netstat diagnostyka sieci dns adres ip łączność awaria
