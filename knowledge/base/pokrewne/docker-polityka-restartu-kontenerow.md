# Docker: polityka restartu kontenerów

### Jaką politykę restartu ustawić, żeby kontener wstawał po awarii i po restarcie komputera?
Docker ma cztery polityki restartu, które ustawia się opcją --restart przy docker run albo w pliku compose. Domyślna no nigdy nie restartuje kontenera. on-failure restartuje tylko wtedy, gdy kontener zakończy się kodem błędu, a opcjonalnie można ograniczyć liczbę prób, np. on-failure:5. always restartuje zawsze, także po restarcie demona Dockera. unless-stopped działa jak always, z jednym wyjątkiem: kontener zatrzymany ręcznie nie wstaje po restarcie demona. Przy ręcznym zatrzymaniu polityka jest ignorowana do restartu demona albo ręcznego uruchomienia kontenera, co zapobiega pętli restartów. Zmiana polityki działającego kontenera jest możliwa poleceniem docker update --restart=unless-stopped nazwa. Wybór polityki dla konkretnej usługi zostaje po stronie administratora; źródło nie zaleca jednej wartości dla wszystkich usług (wniosek z ogólnej wiedzy).
