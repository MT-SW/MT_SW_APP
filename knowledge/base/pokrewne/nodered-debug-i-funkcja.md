### Do czego służy węzeł debug w Node-RED?
Węzeł debug pokazuje wiadomości w panelu Debug, w uporządkowanym widoku. Każdy wpis pokazuje czas odbioru i węzeł, który go wysłał. Kliknięcie identyfikatora węzła pokazuje go w obszarze roboczym.

Słowa: node-red, debug, panel debug, wiadomości, węzeł
Źródło: https://nodered.org/docs/user-guide/nodes (sprawdzono 2026-10)

### Dlaczego warto wyłączać nieużywane węzły debug w Node-RED?
Dokumentacja zaleca wyłączanie lub usuwanie nieużywanych węzłów debug. Przycisk węzła włącza i wyłącza jego wyjście.

Słowa: node-red, debug, wyłączanie, wydajność, przycisk węzła
Źródło: https://nodered.org/docs/user-guide/nodes (sprawdzono 2026-10)

### Jak węzeł debug pokazuje wiadomości w Node-RED?
Węzeł może wysyłać wszystkie wiadomości do logu runtime albo pokazać skróconą wersję, do 32 znaków, w tekście statusu pod węzłem.

Słowa: node-red, debug, log runtime, 32 znaki, status węzła
Źródło: https://nodered.org/docs/user-guide/nodes (sprawdzono 2026-10)

### Co robi węzeł function w Node-RED?
Węzeł function pozwala uruchamiać kod JavaScript na wiadomościach przechodzących przez niego. Szczegóły obsługi obiektów msg są w osobnym przewodniku o pisaniu funkcji, który trzeba otworzyć osobno.

Słowa: node-red, function, JavaScript, msg, funkcja, przewodnik
Źródło: https://nodered.org/docs/user-guide/nodes (sprawdzono 2026-10)
