### Czym jest interfejs webowy Syncthing?
Interfejs webowy Syncthing to wbudowany interfejs użytkownika oparty na HTML i JavaScript, którym steruje się z przeglądarki. Link do GUI i API jest wypisywany wśród pierwszych komunikatów w logu.

Słowa: syncthing, gui, interfejs webowy, HTML, JavaScript, przeglądarka, log
Źródło: https://docs.syncthing.net/users/syncthing.html (sprawdzono 2026-10)

### Jak wygląda przykładowy adres GUI Syncthing?
Dokumentacja pokazuje `0.0.0.0:8384` jako przykład dla opcji `--gui-address`. Domyślnego adresu strona nie podaje w odczytanej części.

Słowa: syncthing, gui-address, 8384, 0.0.0.0, adres GUI
Źródło: https://docs.syncthing.net/users/syncthing.html (sprawdzono 2026-10)
