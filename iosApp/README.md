# MT_SW na iPhone'a (iosApp)

Skorupa aplikacji iOS. Cały ekran rysuje wspólny kod Kotlin (moduł `iosShared`, Compose Multiplatform), a Swift tylko go osadza.

## Uruchomienie (Mac z Xcode)
0. Raz (silnik AI, potrzebny `cmake`): `./scripts/build-llama-ios.sh`. Powstaje `native/ios/llama.xcframework` (nie trafia do repozytorium).
1. Framework Kotlin: `./gradlew :iosShared:linkDebugFrameworkIosSimulatorArm64`
2. Projekt Xcode generuje XcodeGen z pliku `project.yml` (`brew install xcodegen`, potem `xcodegen` w tym folderze).
3. Otwórz `MTSWApp.xcodeproj`, wybierz symulator lub iPhone'a, w zakładce Signing & Capabilities wybierz swoje Apple ID (Team) i uruchom.

Na darmowym Apple ID aplikacja działa 7 dni, potem trzeba ją wgrać ponownie. Bluetooth nie działa w symulatorze, do niego potrzebny jest prawdziwy iPhone.

## Stan
Działa: start aplikacji, ekran powitalny, zakładki (węzły, wiadomości, mapa, połączenia, ustawienia), zapis ustawień i bazy, połączenie z radiem przez Bluetooth i Wi-Fi (z wyszukiwaniem w sieci), powiadomienia, GPS, kompas, barometr, linki `meshtastic://`, wybór i zapis zdjęć, mikrofon, asystent, tłumacz i dyktowanie AI na urządzeniu (modele pobierane w aplikacji). Działa też aktualizacja firmware radia z iPhone'a, widok 3D urządzeń, panorama terenu i przycisk „Wymuś zatrzymanie aplikacji”. Jeszcze nie ma: przechowywania haseł w Keychain (na razie prywatny folder aplikacji) i widoku AR z aparatem. Plik `.ipa` bez podpisu (AltStore / Sideloadly), jeden na iPhone'a i iPada: `./scripts/build-ios-ipa.sh` albo na GitHubie Actions > „Build Binaries (Manual)” > „iPhone i iPad”.

# MT_SW on iPhone (iosApp)

The iOS app shell. The whole screen is drawn by shared Kotlin code (module `iosShared`, Compose Multiplatform); Swift only hosts it.

## Running (Mac with Xcode)
0. Once (AI engine, needs `cmake`): `./scripts/build-llama-ios.sh`. It creates `native/ios/llama.xcframework` (not stored in the repository).
1. Kotlin framework: `./gradlew :iosShared:linkDebugFrameworkIosSimulatorArm64`
2. The Xcode project is generated by XcodeGen from `project.yml` (`brew install xcodegen`, then `xcodegen` in this folder).
3. Open `MTSWApp.xcodeproj`, pick a simulator or an iPhone, choose your Apple ID (Team) under Signing & Capabilities and run.

With a free Apple ID the app works for 7 days and must then be installed again. Bluetooth does not work in the simulator; a real iPhone is needed for it.

## Status
Working: app start, welcome screen, tabs (nodes, messages, map, connections, settings), saved settings and database, radio link over Bluetooth and Wi-Fi (with network search), notifications, GPS, compass, barometer, `meshtastic://` links, picking and saving pictures, microphone, on-device AI assistant, translator and dictation (models are downloaded in the app). Radio firmware update from the iPhone, the 3D device view, the terrain panorama and the "Force stop app" button work too. Not yet: Keychain storage of secrets (for now the app's private folder) and the AR camera view. Unsigned `.ipa` (AltStore / Sideloadly), one file for iPhone and iPad: `./scripts/build-ios-ipa.sh` or on GitHub Actions > "Build Binaries (Manual)" > "iPhone i iPad".

## App Store (wymagania Apple / Apple requirements)
PL: Plik `MTSWApp/PrivacyInfo.xcprivacy` (manifest prywatności) jest w aplikacji. Apple przyjmuje wysyłki tylko z Xcode 26 lub nowszego (SDK iOS 26) — workflow GitHub wybiera najnowszy zainstalowany Xcode. Do App Store Connect potrzebne są jeszcze: adres polityki prywatności, adres wsparcia, opisy i zrzuty ekranu oraz odpowiedź o szyfrowaniu (eksport).
EN: The `MTSWApp/PrivacyInfo.xcprivacy` privacy manifest is part of the app. Apple accepts uploads only from Xcode 26 or newer (iOS 26 SDK) — the GitHub workflow picks the newest installed Xcode. App Store Connect also needs a privacy policy URL, a support URL, descriptions and screenshots, and the export (encryption) answer.

PL: Wersja do App Store: Apple nie pozwala na link do zbiórki (Ko-fi) w aplikacji, więc przy `IPA_APP_STORE=YES ./scripts/build-ios-ipa.sh` sekcja „Wesprzyj projekt" jest ukryta (także w wyszukiwarce ustawień). Zwykły `.ipa` (AltStore/Sideloadly) i pozostałe platformy mają ją bez zmian. Link do Ko-fi umieść w opisie i w adresie wsparcia w App Store Connect.
EN: App Store build: Apple does not allow a donation link (Ko-fi) inside the app, so with `IPA_APP_STORE=YES ./scripts/build-ios-ipa.sh` the "Support the project" section is hidden (also in settings search). The plain `.ipa` (AltStore/Sideloadly) and all other platforms keep it. Put the Ko-fi link in the description and the support URL in App Store Connect.
